# WOODERA Studio — starter site

Статический мобильный сайт-визитка для `woodera-studio.ru`.

## Что уже сделано
- адаптивная главная страница;
- утверждённый логотип WOODERA из пользовательской библиотеки;
- реальная ссылка на VK: `https://vk.com/wooderatver`;
- разделы: изделия, о бренде, уход, контакты;
- SEO title/description, canonical и Open Graph basics;
- `CNAME`, `robots.txt`, `sitemap.xml` для будущего GitHub Pages.

## Что нужно подставить перед публикацией
1. Telegram — точная ссылка или username.
2. Email — адрес для покупателей.
3. Ozon — ссылка на витрину/магазин.
4. Отобранные фотографии товаров и интерьеров.
5. При желании отдельные страницы `/care`, `/catalog`, `/contacts`.

## GitHub Pages
После создания отдельного публичного репозитория:
1. загрузить содержимое этой папки в корень репозитория;
2. Settings → Pages → Deploy from a branch → `main` / root;
3. добавить `woodera-studio.ru` как Custom domain;
4. у регистратора настроить DNS для GitHub Pages;
5. включить Enforce HTTPS после выпуска сертификата.
