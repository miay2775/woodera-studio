# WOODERA — карагач 62 × 57 × 45 см

Готовые модули: mobile — 960 × 960 px; desktop — 1440 × 720 px. В каждом наборе 8 JPG, имена и порядок совпадают. Использованы все 7 интерьерных фотографий нового стола и созданная главная карточка с инфографикой (модуль 08). Цвет и геометрия фотографий при вёрстке не перегенерировались.

## Загрузка

1. JSON для Песочницы Ozon: ozon-richcontent.json. В нём уже соединены компьютерные изображения src, мобильные srcMobile и полноценные текстовые блоки. JSON не загружает товар и не меняет карточку автоматически.
2. Если собираете вручную в визуальном редакторе: создайте 8 блоков в порядке 01–08; добавьте desktop и mobile пару к каждому блоку, затем соответствующий абзац из texts/04_rich_text.txt.
3. Название, аннотация и описание находятся в texts. Аннотацию сохраните в поле товара даже при наличии рич-контента.
4. Для просмотра откройте preview.html или GitHub Pages: https://woodera-studio.ru/rich-content/karagach-62x57/preview.html

## Факты

Столешница 62 × 57 см, толщина 5 см, высота с ножками 45 см, вес 9,5 кг. Ножки: три шпильки, по три прутка. Упаковочные габариты и вес не заменять габаритами изделия.

Источники правил: https://rich-content.ozon.ru/ и https://seller.ozon.ru/media/boost/chto-takoe-rich-kontent-i-kak-ego-sozdat/ . JSON проверен по опубликованной схеме Ozon: https://st.ozone.ru/s3/artifact/schema.json .
