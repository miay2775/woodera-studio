# WOODERA · карагач 62 × 57 см · v2

В комплекте 8 модулей в двух форматах: desktop — 1440 × 720 px; mobile — 960 × 960 px. Порядок и имена изображений совпадают. Использованы все восемь предоставленных кадров, включая главную карточку.

Подтверждённые параметры: столешница 62 × 57 см; толщина 5 см; высота с ножками 45 см; вес 9,5 кг. Монтажные пластины ножек крепятся на саморезах. Отделка — премиальные итальянские масло и твёрдый карнаубский воск.

## Как загрузить

1. Файл `ozon-richcontent.json` содержит готовый рич-контент: для каждой пары связаны desktop (`src`) и mobile (`srcMobile`), добавлены текстовые блоки.
2. Вставьте содержимое JSON в поле Rich-контента Ozon или откройте его в Песочнице. Изображения должны быть доступны по прямым ссылкам.
3. Для ручной сборки используйте изображения 01–08 и соответствующие абзацы из `texts/04_rich_text.txt`.
4. Название, аннотация, описание и характеристики находятся в `texts`.

Предпросмотр: https://woodera-studio.ru/rich-content/karagach-62x57/v2/preview.html

Подготовка комплекта не меняет карточку товара на Ozon автоматически.
