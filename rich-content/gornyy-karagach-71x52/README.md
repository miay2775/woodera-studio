# WOODERA — горный карагач 71×52×48 см

Комплект Rich-контента для Ozon. Это отдельное изделие из горного карагача, не смешивать с каповым клёном или горным тополем.

- desktop/: 8 JPG, размер 1416×708, имена 01.jpg–08.jpg.
- mobile/: 8 JPG, размер 1000×1000, имена 01.jpg–08.jpg.
- brand/: только утверждённый логотип WOODERA Classic.

Характеристики: столешница 71×52 см, толщина 8 см, высота 48 см; масло + твёрдый воск; три чёрные ножки-шпильки, у каждой три прутка.

**Важное замечание:** изображения пока не опубликованы. Прямые ссылки заработают только после загрузки файлов. Основной сайт не содержит навигационных ссылок на эту папку, однако изображения должны быть доступны по прямым HTTPS-адресам для Ozon.
