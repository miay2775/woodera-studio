# WOODERA | Каповый горный тополь | Rich content

Отдельный товар, не смешивать с `rich-content/kapovy-klen`.

## Загрузки

В `desktop/` загружаются **8** файлов `01.jpg`–`08.jpg` размером 1416×708.
В `mobile/` загружаются **8** файлов `01.jpg`–`08.jpg` размером 1000×1000.
Кадры имеют одинаковый порядок в обеих папках.

Для удобной загрузки с телефона:
- Desktop: https://github.com/miay2775/woodera-studio/upload/main/rich-content/gornyy-topol-kapovyy/desktop
- Mobile: https://github.com/miay2775/woodera-studio/upload/main/rich-content/gornyy-topol-kapovyy/mobile

После загрузки изображения будут доступны через `raw.githubusercontent.com`; только тогда используйте `ozon-richcontent.DRAFT.json` как код в поле Rich-контента Ozon.

**На основном сайте нет ссылок на эту папку.** Она доступна всем, кто знает прямой адрес, иначе Ozon не смог бы получать изображения.

## Изделие

- Каповый горный тополь, цельный спил, единственный экземпляр.
- Размер 50 × 50 см, толщина 6,5 см, высота 46,5 см, вес 8 кг.
- Трещины стабилизированы эпоксидной смолой.
- Итальянское грунтовочное масло + итальянский карнаубский воск.
- Подлинный логотип WOODERA Classic — в папке brand.
